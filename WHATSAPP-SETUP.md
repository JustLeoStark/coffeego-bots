# Подключение WhatsApp Business API — пошагово

Дата: 09.09.2026. Путь выбран: **Meta Cloud API напрямую**, **новый отдельный номер**.

Код бота готов полностью. Осталось получить доступы у Meta — это делаете вы, потому что там нужен вход в ваши аккаунты и загрузка документов компании.

---

## Что понадобится заранее

- **Новый номер телефона**, на котором НЕТ обычного WhatsApp. Подойдёт eSIM или дешёвая сима du/Etisalat. Номер должен принимать SMS или звонок для подтверждения.
- **Торговая лицензия ОАЭ** (trade licence) — файлом. Название компании в лицензии должно совпадать с тем, что укажете в Meta.
- **Подтверждение адреса компании**: счёт за коммунальные услуги, аренду или банковская выписка не старше трёх месяцев, с тем же названием и адресом.
- **Рабочая почта на домене** coffee-go.ae. Meta не любит gmail при верификации бизнеса.
- Аккаунт Facebook (личный) — он станет администратором. Двухфакторную защиту включить обязательно, иначе Meta не пустит дальше.

---

## Шаг 1. Meta Business Account

1. Откройте `business.facebook.com`, войдите под личным Facebook.
2. Создайте бизнес-портфель: **Settings → Business portfolio → Create**.
3. Заполните: юридическое название как в лицензии, сайт coffee-go.ae, почта на домене.
4. Добавьте себя администратором, включите двухфакторную защиту.

## Шаг 2. Верификация бизнеса

1. **Settings → Business verification → Start verification**.
2. Загрузите торговую лицензию и подтверждение адреса.
3. Meta проверит совпадение названия, адреса и домена. Домен coffee-go.ae подтвердите отдельно: **Brand safety → Domains → Add**, положите мета-тег на сайт (это сделаю я, когда дадите код).
4. Ждать от двух дней до двух недель. Отказ — обычно из-за несовпадения названия или устаревшего документа; можно подать заново.

## Шаг 3. Приложение и WhatsApp

1. `developers.facebook.com` → **My Apps → Create App → Business**.
2. Привяжите к бизнес-портфелю из шага 1.
3. В приложении: **Add product → WhatsApp → Set up**.
4. Создастся тестовый номер — он для проверки, боевым не будет.

## Шаг 4. Ваш номер

1. **WhatsApp → API Setup → Add phone number**.
2. Введите новый номер, укажите отображаемое имя **CoffeeGo** и категорию Food & Beverage.
3. Подтвердите номер кодом из SMS или звонка.
4. Скопируйте **Phone number ID** — это не сам номер, а внутренний идентификатор.

Отображаемое имя проходит модерацию отдельно, обычно за сутки. Пока оно на проверке, номер уже работает.

## Шаг 5. Постоянный токен

Токен из панели разработчика живёт 24 часа — он не годится.

1. `business.facebook.com` → **Settings → Users → System users → Add**.
2. Имя: `coffeego-bot`, роль **Admin**.
3. **Assign assets** → ваше приложение и WhatsApp Account → полный доступ.
4. **Generate new token** → выберите приложение → права `whatsapp_business_messaging` и `whatsapp_business_management` → срок **Never**.
5. Скопируйте токен сразу — второй раз он не покажется.

## Шаг 6. Ключи мне

Понадобятся четыре значения:

| Что | Где взять |
|---|---|
| `WHATSAPP_TOKEN` | токен системного пользователя из шага 5 |
| `WHATSAPP_PHONE_ID` | Phone number ID из шага 4 |
| `WHATSAPP_APP_SECRET` | App Settings → Basic → App Secret |
| `WHATSAPP_VERIFY_TOKEN` | придумайте любую строку, например `coffeego-wh-2026` |

Пришлите их — я пропишу в переменные Render. **Не публикуйте их нигде больше**: токен даёт полный доступ к переписке от имени компании.

## Шаг 7. Вебхук

Это делаю я после получения ключей, но если хотите сами:

1. В приложении: **WhatsApp → Configuration → Webhook → Edit**.
2. Callback URL: `https://coffeego-bots.onrender.com/whatsapp/webhook`
3. Verify token: строка из шага 6.
4. **Verify and save** — Meta дёрнет адрес и должна получить ответ.
5. **Manage → подписаться на поле `messages`**. Без этой подписки сообщения приходить не будут — самая частая ошибка.

## Шаг 8. Проверка

1. Напишите на новый номер с личного WhatsApp.
2. Бот должен ответить меню.
3. Если тихо — откройте `https://coffeego-bots.onrender.com/whatsapp/health`, там видно, какие переменные заданы.

## Что нужно знать про правила Meta

**Окно 24 часа.** Свободно переписываться можно только 24 часа с последнего сообщения клиента. После этого — лишь готовые шаблоны, прошедшие модерацию. Для helpdesk это не помеха: клиент пишет первым.

**Шаблоны.** Если захотим писать первыми (напоминание о заказе, счёт), нужно создать шаблон в **WhatsApp Manager → Message templates** и дождаться одобрения, обычно сутки. Скажете — напишу тексты.

**Лимиты.** Старт — 1000 уникальных диалогов в сутки, дальше растёт автоматически при хорошей репутации. Первые 1000 диалогов в месяц бесплатны, сервисные (когда клиент пишет первым) сейчас вообще без платы.

**Качество номера.** Meta следит за жалобами. Блокировки ловят тех, кто рассылает без запроса. У нас входящий helpdesk — риск минимальный.

## Про хостинг — предупреждение

Бот живёт на бесплатном Render, который засыпает после 15 минут тишины и просыпается около минуты. Telegram переживает это: он повторяет доставку долго. **Meta ждёт ответа несколько секунд** — первое сообщение клиента может потеряться, а он увидит молчание.

Я добавил самопинг каждые десять минут, это удержит сервис в бодрствовании. Но бесплатный Render всё равно даёт 750 часов в месяц на аккаунт — при постоянной работе одного сервиса как раз впритык.

Если WhatsApp пойдёт всерьёз, стоит перевести бота на платный тариф Render (7 долларов в месяц) — тогда он не спит вовсе. Решать вам, но с живыми клиентами я бы не экономил.

## Что уже сделано в коде

- Приём и разбор сообщений: текст, кнопки, фото и документы (жалобы «не налил» приходят фотографией).
- Проверка подписи Meta — чужой запрос бот отвергнет.
- Защита от повторов: Meta переотправляет вебхук, пока не получит 200, и без защиты клиент получал бы один ответ несколько раз.
- Разбиение длинных ответов: WhatsApp обрезает всё длиннее 4096 символов.
- Повторы при отправке, если сеть моргнула.
- Имя клиента из профиля WhatsApp попадает в уведомление сотруднику.
- Статусы доставки логируются — видно, если сообщение не дошло.
- Тот же движок, что у Telegram: меню, AI-ассистент, передача живому сотруднику.
